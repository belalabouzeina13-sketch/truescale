00Settings

How to get a token
  1. On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → truescale.
  3. Permissions → Repository → Contents: Read and write.
  4. Generate, copy, paste it here. It stays on this device only.

Every unlock key is made from this passphrase. Use a long one you won't forget — if you change it, old orders can't be unlocked anymore.
